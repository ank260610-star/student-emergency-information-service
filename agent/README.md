# NK 智行 Agent

NK 智行是校园地图的智能交互层：理解用户的出行或地点讲解需求，优先使用两校区自建 POI，必要时调用高德兜底，并把结果交给网站绘制唯一的路线轨迹。

## 当前能力边界

- 支持八里台、津南两校区；用户正在浏览的地图即为默认校区。
- 用户未说明起点时，优先使用网站已授权的当前位置；定位不可用时允许手动输入或地图点选。
- `data/poi.seed.json` 保存最新现场采集 POI，坐标统一按 GCJ-02 使用；自建 POI 精确命中时优先于高德检索。
- 同名地点按 `campus + name/alias` 联合识别，不得跨校区混用。
- `data/NK智行两校区POI与地点讲解知识库.md` 用于 NK-GeniOS 知识库检索，同时包含校史地标、学院和普通建筑的基础介绍。
- 路线轨迹必须由网站路线服务或已配置工具返回。Agent 不自行编造逐路转向、距离或时长。
- 开放时间、门禁、办公室分布和活动安排属于动态信息，必须提示以学校、学院官方渠道或现场标识为准。

## NK-GeniOS 配置

1. 将 `NK_ZHIXING_SYSTEM_PROMPT.md` 的正文设置为主智能体提示词。
2. 上传并启用 `data/NK智行两校区POI与地点讲解知识库.md`。
3. 保留天气、高德地点检索、步行、骑行、驾车与现有“校园导航”工作流。
4. 网站上下文标记包括：`【当前校区已确定】`、`【当前校区地点消歧】`、`【用户已选择出行方式】`、`【本次导航起点】`、`【网页导航协同】`、`【地点检索资料】`。
5. 使用 `data/evaluation-cases.json` 和 `Agent演示能力清单与测试语料.md` 回归测试。

## 数据源优先级

1. 网站已确认的当前校区、点选地点、出行方式和当前位置。
2. 自建 POI 与本站审核的地点讲解资料。
3. 高德地点与路线服务兜底。

若地点存在于自建库但路线工具不可用，仍不得伪造路线；应明确说明服务暂不可用，并保留地点识别结果。

## 紧急场景

涉及人身安全、医疗急症、火灾或违法犯罪时，优先建议联系 110、119、120 或学校现场求助渠道，不以普通导航替代专业救援，不承诺响应时间。

## 数据维护

- 机器结构：`data/poi.seed.json`
- NK-GeniOS 上传文档：`data/NK智行两校区POI与地点讲解知识库.md`
- 系统提示词：`NK_ZHIXING_SYSTEM_PROMPT.md`
- 测试集：`data/evaluation-cases.json`

每次更新 POI 时需检查：校区、别名、经纬度顺序、坐标系、重复地点、多个入口、动态信息提示和跨校区同名冲突。
